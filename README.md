# Terminator

> **Self hosted** autonomous ai agent that never stops.

## What does it do? (or, at least aims)

Be a helpful assistant through hard and repetitive problems

> It will remember you !

It aims to be autonomous rag agent thatt you can communicate through http or its cli.

## Sandbox first

Agents operating inside a **burner**(we can say throwaway too) docker container

> What i mean by burner is it destroys the container after usage

## Used,
- Langchain
- LangGraph
- Python
- Docker sdk
- Playwright (for browser usage of the agent)

## Status

**Under development.**

## Mission

Give the agent an objective, an environment, and the tools it needs.
